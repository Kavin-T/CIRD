# CIRD Inventory Management System

A full-stack web application developed for **CIRD, PSG College of Technology** to manage equipment rentals. The system replaces traditional paper-based workflows with a digital platform, enabling real-time tracking, secure authentication, and transparent approval processes.  

## 🚀 Features
- 📦 **Equipment Rentals Management** – Handles 40+ machines and their usage.
- 🔐 **Google Authentication** – Provides secure login for users and administrators.  
- 👥 **Role-Based Access Control** – Different permissions for staff, faculty, dean, and principal.  
- 📝 **Multi-Level Approval Workflow** – Requests move seamlessly through hierarchical approvals.  
- 📄 **Form Uploads** – Users can upload rental-related forms.  
- ⏱ **Real-Time Status Tracking** – Users can see where their request is pending.  
- 📊 **Rental History** – Complete transparency on past rentals.  
- ⏳ **Efficiency Boost** – Saves ~30 hours/month of manual administrative effort.  

## 🛠️ Tech Stack
- **Frontend:** React.js, Material-UI  
- **Backend:** Express.js, Node.js  
- **Database:** MySQL  
- **Version Control:** Git & GitHub
